# WCAG 2.1 Contrast Standards & Mathematical Verification

Every color decision generated by this skill is mathematically verified against the **WCAG 2.1 AA (4.5:1 / 3:1)** and **AAA (7:1 / 4.5:1)** specifications.

---

## 1. Compliance Thresholds

| UI Element Type | WCAG AA Minimum | WCAG AAA Minimum | Role in Token System |
| :--- | :--- | :--- | :--- |
| **Normal Body Text (< 18pt / 24px)** | **4.5:1** | **7.0:1** | `text-foreground` on `bg-background` / `bg-surface` |
| **Large Text (≥ 18pt / 24px or 14pt bold)** | **3.0:1** | **4.5:1** | H1/H2 headings, display metric numbers |
| **Essential UI Components & Borders** | **3.0:1** | **3.0:1** | `border-border`, input boundaries, active tab bars |
| **Focus Indicators (Keyboard Ring)** | **3.0:1** | **3.0:1** | `ring-ring` against adjacent surfaces |
| **Button Text on Primary Accent** | **4.5:1** | **7.0:1** | `text-primary-foreground` on `bg-primary` |
| **Incidental / Disabled Text** | No Requirement | No Requirement | `disabled:opacity-40` |

## 2. Mathematical Relative Luminance Formula

Contrast ratio $C$ between two colors with relative luminances $L_1$ (lighter) and $L_2$ (darker) is defined as:

$$C = \frac{L_1 + 0.05}{L_2 + 0.05}$$

Where relative luminance $L$ of an sRGB color $(R, G, B)$ is calculated as:

$$L = 0.2126 \times R_s + 0.7152 \times G_s + 0.0722 \times B_s$$

For each channel $C \in \{R/255, G/255, B/255\}$:
- If $C \le 0.03928 \implies C_s = C / 12.92$
- If $C > 0.03928 \implies C_s = \left(\frac{C + 0.055}{1.055}\right)^{2.4}$

### General Rules for Foreground Determination
- When the accent color (`bg-primary`) is dark (e.g. Navy, Dark Indigo, Emerald, Deep Charcoal), pair with pure white text (`#ffffff`).
- When the accent color is high-luminance (e.g. Neon Lime, Yellow, Cyan, Light Amber), pair with deep obsidian text (`#09090b` or `#161616`) to guarantee minimum 4.5:1 contrast.
